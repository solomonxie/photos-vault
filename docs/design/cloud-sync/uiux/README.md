# Extension: screen map

Desktop width 78 cols. Glyphs: the `uiux` skill's `notation.md`.

```text
   toolbar icon
        │
        ▼
   ┌ Setup ┐──save ok──▶ Waiting-for-phone ──checkpoint appears──┐
   └───────┘                                                     ▼
                     ┌──────────── sidebar (always) ──────────────────┐
                     │ Photos  Albums  People  Places  Bin   ⚙        │
                     └──┬────────┬────────┬───────┬──────┬──────┬─────┘
                        ▼        ▼        ▼       ▼      ▼      ▼
                     Library   Albums  People  Places   Bin   Setup (edit)
                        │        │ tap    │ tap   │ tap
                        │        ▼        ▼       ▼
                        │      Album    Person  Place     ← all are the same day grid
                        ▼
                   🔍 Search ─▶ Results (same grid)
   any grid ──tile──▶ Viewer overlay ──Esc──▶ same grid, same scroll
   any page ──drop files──▶ Upload tray (docked)
   status chip ──click──▶ Sync panel (popover)
```
